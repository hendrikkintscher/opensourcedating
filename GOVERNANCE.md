# Governance

## Who runs the project

The project is currently maintained by Hendrik Kintscher ([@hendrikkintscher](https://github.com/hendrikkintscher)).

The project is founding a registered non-profit association (eingetragener Verein, e.V.) in Berlin now (decided 12 Oct 2026). The seven founding members needed for an e.V. are being gathered, and the association is to be founded before any public announcement or grant press, not only before real users join. It will operate the service, be its GDPR controller and own the project's assets. Until then the maintainer is personally the controller and liable.

Grant applications that are due before the association exists (for example the Prototype Fund, which funds individuals) go in under the maintainer's name.

## The project is not for sale

The project, its name, its code and its user data are not for sale, and will not be handed to a commercial dating company in any form. In particular:

- The code is AGPL-3.0-or-later and stays free software. There is no contributor licence agreement, so the copyright is shared by all contributors and the project can't be relicensed under closed terms.
- Once the association exists, the project's assets (trademark, domains, app store accounts, signing keys and server contracts) will be transferred to it. Until then the maintainer holds them in trust for the project.
- The association's statutes will forbid selling or exclusively licensing these assets to a for-profit company.

## Funding

All funding is published. No funder gets control over the project's decisions.
