# Security policy

This project handles sensitive data (dating profiles, location, private messages), so we take security reports seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub's [private vulnerability reporting](../../security/advisories/new) for this repository.

Include what you found, how to reproduce it, and what an attacker could do with it.

## What to expect

- We confirm receipt within 7 days.
- We aim to fix serious issues within 90 days and will keep you informed.
- We publish an advisory once a fix is available and credit you, unless you prefer not to be named.

## Current status

The project is in an early prototype phase and runs on test data only. It has not yet had an independent security review, so please don't use it with real personal data.
