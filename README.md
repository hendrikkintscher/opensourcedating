# opensourcedating

*Working title; no brand name has been chosen yet.*

A free, open-source dating app for Android and iOS, planned first for Berlin. It starts on one
server run by a Berlin non-profit association and later grows into a network of vetted servers.
People find each other by searching with filters, never by swiping; anyone can write one opening
message to anyone, and a reply starts the conversation. Chats are end-to-end encrypted. The
project is in its planning phase: nothing is built yet, and only test data is ever used.
